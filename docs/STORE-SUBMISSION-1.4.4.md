## 3. 審査で見られる点

- **単一目的からの逸脱に見えないか**。OCR も画面キャプチャも「閲覧中のページの文字を読み上げる」ためだけに存在することが、説明文から読み取れる状態にしておく。
- **リモートコードの不使用**。Tesseract.js 本体・WASMコア・日本語学習データはすべて同梱しており、実行時に外部から取得するものは無い。`wasm-unsafe-eval` は同梱WASMの実行にのみ必要。CI の「リモートコードを実行していないことの確認」で機械的にも担保している。
- **`<all_urls>` の追加**。v1.2.1 の時点で `content_scripts.matches` が既に `<all_urls>` のため、権限警告は増えない（＝既存ユーザーが自動的に無効化されることはない）。理由は権限の使用理由の欄に記載済み。

## ストア掲載用の「詳細な説明」（日本語）

以下をそのまま貼り付ける。

```
閲覧中のWebページの文字を、VOICEVOXの音声で読み上げるChrome拡張機能です。
選択したテキストだけでなく、画像・PDF・電子書籍の中の文字も読み上げます。

■ 読み上げにはVOICEVOXが必要です

音声の合成は、お使いのPCで動いているVOICEVOXが行います。読み上げる文章が開発者や第三者のサーバーへ送られることはありません。ご利用の前に、公式サイト（https://voicevox.hiroshiba.jp/）からVOICEVOXをインストールし、起動しておいてください。

メモリ使用量を抑えたい方へ: VOICEVOXの画面を開かず、すでにお使いのPCに入っている音声合成エンジンだけを起動して使うこともできます。新しく何かをダウンロードする必要はありません。設定は最初の1回だけで、以降はパソコンを起動するだけで読み上げられる状態になります。実測でおよそ590MBのメモリが空きます。

手順は、拡張機能のオプション画面の下部と、下記のページでご案内しています。
https://github.com/ningengakushu-dot/Web-Reader-for-VOICEVOX#voicevoxの画面を出さずに使うメモリ節約

■ できること

・テキストを選択して読み上げ
　右クリックメニューまたはショートカット（Alt+Shift+U）で読み上げます。再生中に別のテキストを選んで指示すると、すぐ切り替わります。

・範囲をドラッグして読み上げ
　閲覧中のページの上で読みたい範囲をドラッグするだけで読み上げます。ページの表示やサイズは一切変わらないため、本文を目で追いながら聞けます。通常のWebページではページが持っている文字をそのまま読み取るため、読み間違いがなく待ち時間もほとんどありません。

・画像・PDFの中の文字を読み上げ（β版）
　文字として選択できない範囲は、自動的に文字認識（OCR）へ切り替わります。画像内の文字、PDF、電子書籍ビューア、コピー禁止サイト、スクリーンショットが対象です。縦書き・横書きは自動判定するため、縦書きの小説にも対応します。PDFビューアなど範囲選択ができない画面では、キャプチャ画像のタブが開き、範囲選択と認識結果の編集ができます。

・声と話し方の調整
　お使いのVOICEVOXに入っているキャラクターを選び、速度・音の高さ・抑揚・音量・文の間の長さを調整できます。

・ページ内アイコンのカスタマイズ
　読み上げの開始・停止に使うアイコンは、ドラッグで好きな位置へ移動でき、位置は自動保存されます。大きさは16pxから128pxまで、見た目は「シンプルな円」「このアプリのアイコン」「読み上げキャラクター」「好きな画像」から選べます。

■ OCRはβ版です

文書の種類によっては読み間違いや読み飛ばしが起こり、認識に10〜20秒ほどかかります。枠で囲まれた短いボタンの文字が復元しないこと、表の列の区切りが読み上げに現れないことがあります。文字として選択できるページではOCRを介さないため、これらの制約は当てはまりません。

■ プライバシー

・読み上げるテキストは、お使いのPC内のVOICEVOX（127.0.0.1:50021）にのみ送信されます。
・画面のキャプチャは、ユーザーの明示的な操作を起点にしたときだけ取得します。通常のWebページではページ内の文字を直接読むため、キャプチャは行いません。
・取得した画像は同梱のTesseract.js（WASM）によりブラウザ内でのみ処理され、外部へ送信されることはありません。
・設定はブラウザのローカルストレージにのみ保存されます。
・開発者のサーバーを含め、外部サーバーへユーザーデータを送信・保存することはありません。

■ キャラクター画像について

キャラクター画像は本拡張機能に同梱しておらず、お使いの端末で起動しているVOICEVOXから取得して表示します。画像の権利は各キャラクターの権利者に帰属します。本拡張機能は無償で提供される非商用のソフトウェアであり、各権利者の利用規約にもとづいて画像を表示しています。

■ 動作環境

Chrome 119以降。別途VOICEVOXの起動が必要です（VOICEVOXの画面ではなく、音声合成エンジンのみの起動でも動作します）。

■ ショートカット

・Alt+Shift+U : 選択したテキストの読み上げを開始／停止
・Alt+Shift+O : 画面をキャプチャしてOCR読み上げを開始

割り当てが他の拡張機能と重なっている場合は有効になりません。chrome://extensions/shortcuts で確認・変更できます。

■ 生成した音声を公開する場合

VOICEVOXで生成した音声を公開する場合は、「VOICEVOX:（使用キャラクター名）」のようなクレジット表記が必要です。詳しくはVOICEVOXおよび各キャラクターの利用規約をご確認ください。
```

# プライバシーポリシー

[人間学習]（以下、「提供者」といいます。）は、提供者が提供するChrome拡張機能「Web Reader for VOICEVOX」（以下、「本拡張機能」といいます。）における、ユーザーの個人情報の取扱いについて、以下のとおりプライバシーポリシー（以下、「本ポリシー」といいます。）を定めます。

## 1. 収集する情報とその利用目的
本拡張機能は、Chrome Web Storeの「単一目的（Single Purpose）」ポリシーに従い、**閲覧中のページ上の文字（選択したテキスト、および画像・PDF上の文字を含む）を読み上げる機能を提供することのみ**を目的として動作します。

提供者の管理する外部サーバーへ個人情報を送信・保存することはありません。すべてのデータ処理はユーザーの端末内（ローカル環境）で完結します。

### (1) テキストデータ
- **取得内容**: ユーザーがブラウザ上で選択し、読み上げを指示したテキストデータ。および、画面OCR読み上げ機能で認識されたテキスト（ユーザーが編集した場合は編集後のテキスト）。
- **利用目的**: 音声合成処理を行うため。
- **処理方法**: 当該テキストデータは、ユーザーの端末内で起動している「VOICEVOX」エンジン（`http://127.0.0.1:50021` 等）へ送信されます。提供者のサーバーや第三者のサーバーへ送信されることはありません。

### (2) 設定データ
- **取得内容**: 選択されたキャラクターID、読み上げ速度・音の高さ・抑揚・音量・文の間の長さの設定値、ページ内アイコンのサイズと表示位置、アイコン右クリック時の動作設定、OCRのルビ優先読み設定。
- **利用目的**: 次回利用時にユーザーの設定を保持するため（利便性の向上）。
- **保存場所**: ユーザーのブラウザ内のストレージ領域（`chrome.storage.local`）に保存されます。

### (3) 画面キャプチャ画像（OCR読み上げ機能）
- **取得条件**: 範囲読み上げでは、まず選択範囲のページ内テキストをそのまま取り出します。通常のWebページではこれで完結し、**スクリーンショットの取得は行いません**。画像内の文字・canvas描画・別オリジンのフレームなど、テキストとして取り出せない範囲を選択した場合に限り、以下のキャプチャを行います。
- **取得内容**: 上記の条件に該当する場合に取得する、表示中タブのスクリーンショット画像。
- **利用目的**: 画像内の文字を認識（OCR）し、読み上げ用のテキストを生成するため。
- **処理方法**: 文字認識は拡張機能に同梱されたOCRエンジン（Tesseract.js）により、ユーザーのブラウザ内でのみ実行されます。キャプチャ画像・認識結果が提供者のサーバーや第三者のサーバーへ送信されることは一切ありません。
- **保存場所**: キャプチャ画像は文字認識処理の間、拡張機能内のメモリ上でのみ扱われます。PDFビューア等で使用するタブでの範囲選択方式の場合のみ、ブラウザのセッションストレージ領域（`chrome.storage.session`）に、キャプチャ画像および識別用の元ページのタイトル・URLが一時的に保持され、新しいキャプチャの実行時またはブラウザ終了時に自動的に破棄されます。永続的な保存は行いません。

## 2. データの最小化と秘匿性
本拡張機能は、読み上げ機能の実現に必要最小限の権限のみを要求します。閲覧履歴、保存されたパスワード、クッキーを読み取るAPIは使用していません。また、取得したデータを広告配信やプロファイリング、第三者への販売に利用することは一切ありません。

画面OCR読み上げ機能では、ページ内のテキストを取り出せない範囲を選択した場合に限り、その時点における「表示中のタブの見えている範囲」のスクリーンショットを取得します。取得はユーザー操作（右クリックメニュー、ショートカット、ツールバーアイコン、ページ内アイコン）を起点とする場合に限られ、バックグラウンドで自動的に画面を取得することはありません。この画像には画面上に表示されている情報が含まれ得ますが、端末内の文字認識処理にのみ使用され、外部へ送信・永続保存されることはありません。

## 3. 第三者への提供
本拡張機能は、ユーザーの同意がある場合、または法令に基づく場合を除き、取得した情報を第三者に提供することはありません。
なお、音声合成のために連携する「VOICEVOX」ソフトウェアへのデータ受け渡しは、ユーザー自身のローカルネットワーク内で行われるものであり、インターネットを経由した外部への送信にはあたりません。

## 4. Google API データの限定的使用
本拡張機能の Google API（Chrome API）からの情報使用は、[Chrome Web Store 利用利用者データに関するポリシー](https://developers.google.com/chrome/web-store/program-policies?hl=ja#user_data)（限定的使用要件を含む）に従います。

## 5. 免責事項
本拡張機能からリンクや連携機能によってアクセスできる「VOICEVOX」ソフトウェア等の外部サービスにおける個人情報の取扱いについては、提供者は責任を負いません。

## 6. プライバシーポリシーの変更
提供者は、必要と判断した場合には、ユーザーに通知することなく本ポリシーを変更することができるものとする。変更後のプライバシーポリシーは、本ページに掲載したときから効力を生じるものとします。

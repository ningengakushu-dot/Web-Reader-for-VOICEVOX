# VOICEVOX リーダー Windows 版

本文を貼り付けて読み上げる Windows x64 用ポータブルアプリです。Windows 11 x64 で動作確認しています。音声合成には同じ PC で起動した VOICEVOX を使います。

## 起動と操作

1. VOICEVOX を起動します。エンジンの接続先は `http://127.0.0.1:50021` です。
2. `VOICEVOX-Local-Reader-0.1.1-win-x64.zip` を「すべて展開」し、展開先にある **VOICEVOX-Local-Reader.exe** を開きます。ランタイムは同梱されています。EXE と隣の DLL・resources フォルダーを一緒に保管してください。
3. 本文を入力または貼り付け、話者・スタイル・話速・音量を選び、「読み上げ」を押します。声の高さ、抑揚、間の長さは「声の詳細設定」で調整できます。読み上げるたびに本文の先頭から始まります。「停止」は準備中にも使えます。

本文欄では Ctrl+V または右クリックの「貼り付け」で文章を入力できます。文字や操作項目の大きさは「表示」メニューで拡大・縮小できます。

**Ctrl+Enter** を押すと読み上げ、**Esc** で停止します。Tab と Shift+Tab で項目を移動できます。「VOICEVOXを起動して再接続してください」と表示されたら、本文をそのままにして VOICEVOX を起動し、「再接続」を押してください。

スタートメニューから起動したい場合は、展開先の EXE のショートカットを作成し、エクスプローラーで `shell:programs` を開いてショートカットを置いてください。この版はインストーラーを使用しません。

## データと利用条件

読み上げ設定だけをユーザープロファイルの `settings.json` に保存します。本文・クリップボード内容・WAV をアプリのログや履歴に保存する機能はありません。本文を送る相手は上記のループバックアドレスに限られます。利用者が起動したエンジンの設定やログはエンジン側で管理されます。読める文字を含まない入力、10 万 UTF-16 コード単位を超える本文、分割上限（5,000 件）に達する本文は合成前に画面で案内します。

作成した音声を公開する場合は VOICEVOX と各キャラクターの利用条件に従い、使用した話者のクレジットを表示してください。

## 開発・配布

Windows x64、x64 版 Node.js 24、Windows 標準の `tar.exe` を使用します。リポジトリ直下で実行してください。

```powershell
npm --prefix desktop ci
npm --prefix desktop test
npm --prefix desktop run build
npm --prefix desktop run test:packaged
```

最後のコマンドは起動済みの VOICEVOX と実際の音声出力経路を使い、配布 ZIP を一時フォルダーに展開して画面を操作します。`READER_QA_ENGINE` にインストール済みエンジンの `run.exe` のパスを指定すると、再接続の検査用に別ポートで実エンジンを一時起動します。接続先の差し替えは検査ドライバーのプロセス内計装で行います。出力は `desktop/dist/VOICEVOX-Local-Reader-0.1.1-win-x64.zip` です。開発中は `npm --prefix desktop start` でも同じ画面を開けます。

### 実装の境界

- Electron を同梱し、拡張の `background-speech.js` を既存の正規表現・分割規則ごと出荷します。Windows 用の既存コードはなく、この構成なら JavaScript の移植差を避けながら再生・停止を HTMLAudioElement で制御できます。Chrome 拡張、開発サーバー、利用者による Node.js の導入は不要です。
- メインプロセスが接続先を固定し、入力検証、通信のキャンセル、設定の保存を担当します。画面はローカルの許可済み資材を非永続セッションで開きます。外部スクリプトの読み込みと画面からのネットワーク接続は CSP で制限します。
- 音声は順に 1 件ずつ合成し、再生と次の合成を並行させます。完成音声の先読みは 45 秒・256 件・64 MiB のいずれかに達すると休止します。合成単位ごとに判定するため、最後の 1 件分はしきい値をまたぐことがあります。先頭では直前の実測合成速度と読み上げコストから必要な蓄積量を見積もります。
- 括弧を含む文では、候補の音素列が一致し、新しいアクセント句の境界も生じない場合に、余分な間を減らす候補を採用します。エンジンが HTTP 5xx を返したときは、長い文を最大3段階まで分割して再試行します。回復できない場合も、それ以前の合成済み音声を順に再生し、失敗した位置を表示します。
- 各読み上げ要求が独立したキュー、AbortController、再生中の Audio と Blob URL を所有します。停止・終了時は所有権を先に無効化し、遅延した HTTP 応答やメディアイベントが新しい要求を変更するのを防ぎます。

他アプリの選択文字の取得、グローバルショートカット、画面範囲 OCR は後続候補です。Windows 版の資材は Chrome 拡張の配布許可リストから独立しています。
